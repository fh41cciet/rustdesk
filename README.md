# RustDesk

Your remote desktop software.

## Features

- Cross-platform (Windows, macOS, Linux, Android, iOS)
- Self-hosted or use our public server
- End-to-end encryption
- Low latency and high performance

## Quick Start

1. Download the latest release from the [Releases](https://github.com/rustdesk/rustdesk/releases) page.
2. Install and run.
3. Share your ID with a friend, or connect to their ID.
